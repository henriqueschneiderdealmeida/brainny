<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP client → POST /webhook/evolution | Untrusted: any caller can POST arbitrary JSON; preHandler blocks unauthenticated requests |
| X-Webhook-Secret header value | Untrusted string; compared timing-safely in preHandler; must not appear in logs |
| Evolution webhook body (data field) | Untrusted nested JSON; parsed defensively in extractMessages with explicit type allow-list |
| Queue job execution context | Internal; errors isolated per message via try/catch; queue never crashes on job failure |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-06 | Information Disclosure | Pino access logs (req.headers) | mitigate | Add "req.headers['x-webhook-secret']" to redact list in src/lib/logger.ts; secret replaced with [Redacted] in log output |
| T-02-07 | Tampering | Zod body schema — strict vs passthrough | accept | webhookBodySchema uses z.passthrough() so new Evolution fields never cause 400; inner structure validated defensively in services/ingest.ts with explicit type allow-list |
| T-02-08 | Denial of Service | Route bodyLimit — 25MB base64 media | mitigate | Route-level bodyLimit: 25 * 1024 * 1024 — only POST /webhook/evolution has enlarged limit; other routes keep 10MB default |
| T-02-09 | Denial of Service | Queue job throws → queue stalls | mitigate | Per-message try/catch inside queue.add(); caught errors log with Pino error and do NOT rethrow; queue drains normally |
| T-02-10 | Elevation of Privilege | preHandler bypass via route handler ordering | mitigate | preHandler: [authHandler] declared on route options directly — not as a global hook with conditional skip; auth is route-scoped |
| T-02-SC | Tampering | npm install (no new packages in this plan) | accept | No new npm installs in Plan 02; all packages installed in Plan 01 with verified legitimacy |
</threat_model>
