# Plan 04-01: Chat upsert + persist tests

## Objective

Extend `persistMessage` to also upsert chat metadata (name, isGroup, lastSeenAt) whenever a message is persisted. Add `persist.test.ts` to verify STORE-02 (rawJson stored) and STORE-03 (chat upserted).

## Context

- **Schema:** `chats` table has `id`, `name`, `isGroup`, `lastSeenAt`, `participantsJson` (nullable)
- **NormalizedMessage:** has `chatId`, `senderName`, `timestamp`
- **isGroup detection:** `chatId` ends with `@g.us`
- **Chat name for DMs:** use `senderName` (from pushName), fallback to chatId
- **Pattern:** same DB client as messages insert, same tx-less approach (no FK dep)
- **STORE-02:** rawJson is already set in ingest.ts line 79 — the persist test must confirm the field reaches DB

## Tasks

### Task 1 — Extend `persistMessage` with chat upsert

Extend `src/services/persist.ts`:

```typescript
import { chats, messages } from '../db/schema.js';

export async function persistMessage(
  db: NodePgDatabase<typeof schema>,
  msg: NormalizedMessage,
): Promise<void> {
  // Insert message (idempotent via PK conflict)
  await db.insert(messages).values(msg).onConflictDoNothing();

  // Upsert chat metadata (STORE-03)
  const isGroup = msg.chatId.endsWith('@g.us');
  await db
    .insert(chats)
    .values({
      id: msg.chatId,
      name: msg.senderName ?? msg.chatId,
      isGroup,
      participantsJson: null,
      lastSeenAt: msg.timestamp,
    })
    .onConflictDoUpdate({
      target: chats.id,
      set: {
        name: msg.senderName ?? msg.chatId,
        lastSeenAt: msg.timestamp,
      },
    });
}
```
