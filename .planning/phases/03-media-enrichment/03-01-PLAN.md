    export async function downloadMedia(url: string, allowedHostname: string): Promise<Buffer>
    - Parse url with new URL(url); catch invalid URLs
    - Reject if parsed.protocol !== 'https:' — throw Error('Apenas HTTPS é permitido para download de mídia')
    - Reject if parsed.hostname !== allowedHostname — throw Error('Hostname não permitido para download de mídia: ' + parsed.hostname)
    - Check Content-Length header: const cl = parseInt(response.headers.get('content-length') ?? '0', 10); if cl > 25 * 1024 * 1024 throw before arrayBuffer()
    - fetch with AbortSignal.timeout(30_000)
    - After arrayBuffer(): check buffer.byteLength > 25 * 1024 * 1024, throw if exceeded
    - Return Buffer.from(arrayBuffer)

    export async function storeAsset(buffer: Buffer, messageId: string, ext: string, timestamp: Date, dataDir: string): Promise<string>
    - dateStr = timestamp.toISOString().slice(0, 10)  — use message timestamp, NOT new Date()
    - dir = path.join(dataDir, dateStr, 'assets')
    - await mkdir(dir, { recursive: true })
    - finalPath = path.join(dir, messageId + '.' + ext)

    - await rename(tmpPath, finalPath)  — atomic on same filesystem (Pitfall 7 guard: tmp and final are in the same dir)

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| webhook payload → enrich.ts | msg.mediaUrl is untrusted — comes from Evolution webhook body, could be crafted by attacker |
| Evolution CDN → Node process | Downloaded buffer enters heap — size must be bounded before arrayBuffer() |
| OpenAI API → Node process | APIError responses must be handled; never propagate raw error messages to Evolution |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Elevation of Privilege | downloadMedia — SSRF via crafted mediaUrl | mitigate | Allowlist check: parsed.hostname must equal allowedHostname derived from EVOLUTION_URL env var; reject non-HTTPS; implemented in downloadMedia() before any fetch() call |
| T-03-02 | Denial of Service | downloadMedia — oversized file exhausting heap | mitigate | Check Content-Length header before arrayBuffer(); hard 25MB cap on buffer.byteLength after download; AbortSignal.timeout(30_000) prevents slow-loris |
| T-03-03 | Tampering | enrich.ts — malformed audio crashing Whisper | accept | OpenAI API rejects invalid audio with typed APIError; caught by withRetry onFailedAttempt; never crashes process |
| T-03-04 | Denial of Service | embeddingQueue — oversized text consuming tokens | mitigate | truncateForEmbedding caps at 8000 chars before any embeddings.create call; warn logged (ENRICH-04) |
| T-03-05 | Tampering | openai SDK built-in retry + p-retry double storm | mitigate | maxRetries: 0 set on OpenAI client in openai.ts plugin; p-retry owns all retry logic exclusively |
| T-03-06 | Information Disclosure | Pino logs — OpenAI API key in error output | mitigate | API key is in fastify.config (not in msg or error context); never passed to log calls; existing Pino redact covers password-like fields |
| T-03-SC | Tampering | npm install openai@^5.23 | mitigate | Package Legitimacy Audit in RESEARCH.md: openai [OK] — 6yr-old package, github.com/openai/openai-node, no postinstall script |
