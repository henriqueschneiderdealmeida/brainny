# Plan 05-02: Wire cron into index.ts + graceful shutdown

## Objective

Wire `runMaterialize` into `src/index.ts` as a `node-cron` scheduled task:
- Schedule: `*/5 * * * *` (every 5 minutes), timezone `America/Sao_Paulo`
- Overlap guard: `let running = false` — if a tick fires while the previous is still running, log `materializer: tick skipped (already running)` and return
- Log start, finish (with filesWritten + messagesProcessed), and duration per tick
- Register SIGTERM handler to stop cron and drain queue before exiting (OPS-03 partial)
- `noOverlap: true` in node-cron 4.x as additional guard

## Context

- **node-cron 4.x API**: `cron.schedule(expr, handler, { timezone, noOverlap: true })`; returns a `ScheduledTask` with `.stop()` and `.destroy()` methods
- **runMaterialize** is in `src/services/materialize.ts` — takes `(db, dataDir, tz, log)`
- **DATA_DIR and TIMEZONE** must be added to `src/config.ts` (Zod env vars)
- **SIGTERM/graceful shutdown**: stop cron task, drain `fastify.queue.onIdle()`, then `app.close()`

### Task 2 — Wire cron + overlap guard in `src/index.ts`

After `await app.listen(...)`, add:

```typescript
import cron from 'node-cron';
import { runMaterialize } from './services/materialize.js';

// ...inside main(), after app.listen():

let materializerRunning = false;

const materializerTask = cron.schedule(
  '*/5 * * * *',
  async () => {
    if (materializerRunning) {
      app.log.info('materializer: tick skipped (already running)');
      return;
    }
    materializerRunning = true;
    const tickStart = Date.now();
    app.log.info('materializer: tick started');
    try {
      const result = await runMaterialize(
        app.db,
        config.DATA_DIR,
        config.TIMEZONE,
        app.log,
      );
      const duration = Date.now() - tickStart;
      app.log.info({ filesWritten: result.filesWritten, messagesProcessed: result.messagesProcessed, durationMs: duration }, 'materializer: tick complete');
    } catch (err) {
      app.log.error({ err }, 'materializer: tick failed');
    } finally {
      materializerRunning = false;
    }
  },
  { timezone: config.TIMEZONE, noOverlap: true },
);

// Graceful shutdown
const shutdown = async (signal: string) => {
  app.log.info({ signal }, 'shutting down');
  materializerTask.stop();
  await app.queue.onIdle();
  await app.close();
  process.exit(0);
};
process.on('SIGTERM', () => void shutdown('SIGTERM'));
process.on('SIGINT', () => void shutdown('SIGINT'));
```
